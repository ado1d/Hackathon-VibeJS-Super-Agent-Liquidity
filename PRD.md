# Super Agent Platform PRD — Implementation Source

This repository implements version 1.0 of the supplied **Super Agent Liquidity & Risk Intelligence Platform** final hackathon PRD (11 July 2026). The product is a synthetic-data operational decision-support prototype.

The binding acceptance requirements are: separate provider e-money and shared cash visibility; shortage forecasts; evidence-first unusual-activity alerts; confidence-aware data-quality fallbacks; role-enforced human coordination; four repeatable scenarios; measured validation; and Docker Compose deployment. It must never execute financial actions, use real customer data, or make a final fraud determination.

Detailed behavior is captured in the automated tests and the documents under `docs/`.
