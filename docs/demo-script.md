# 7–9 Minute Demonstration

1. **Problem — 45 seconds:** explain one shared cash reserve and non-interchangeable provider e-money.
2. **Dashboard — 60 seconds:** sign in as Operations; show provider separation, freshness, nearest pressure, and queue.
3. **Scenario A — 75 seconds:** load A in Admin, open Rahman Store, and show Provider A shortage with confidence. Switch the alert explanation to Bengali/Banglish.
4. **Scenario B — 90 seconds:** load B; distinguish shared-cash pressure from unusual repeated activity. Emphasize that the pattern is not proof of fraud.
5. **Scenario C — 60 seconds:** show missing/conflicting feeds, visible confidence deductions, and the suppressed precise forecast.
6. **Scenario D — 90 seconds:** claim, acknowledge, add a note, escalate, switch to Risk, start progress, resolve, and show the timeline.
7. **Evidence — 60 seconds:** show validation metrics, deterministic seed, architecture, tests, privacy, and limitations.
8. **Close — 30 seconds:** connect early liquidity insight, explainable review, and human-owned coordination.
